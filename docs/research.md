## Halo browser-runtime reference

[OpenCE](https://github.com/OpenCommunityEdition/OpenCE/tree/fc9deb0b10eaae1d62caedb0710968b4e77e6e16) is a browser/native port of a Halo Xbox development-build decompilation, rather than a general XBE-to-Wasm translator. Its [web guide](https://github.com/OpenCommunityEdition/OpenCE/blob/fc9deb0b10eaae1d62caedb0710968b4e77e6e16/port/web/README.md) and portable platform sources offer browser-specific references: Xbox Direct3D 8 state translated through the GLES/WebGL2 path in `port/linux/src/d3d8_gl.c`, NV2A shader translators, the SDL3 DirectSound mixer in `dsound_sdl.c`, and controller support in `xinput_sdl.c`. These sources and the maintainer's browser claims were inspected, not executed here; Halo-specific state layouts and behavior do not establish Fuzion Frenzy compatibility.

Useful concrete findings include WebGL2 texture-format and stride restrictions, rebased indices, browser frame scheduling, and [the pinned SDL3 port](https://github.com/OpenCommunityEdition/OpenCE/blob/fc9deb0b10eaae1d62caedb0710968b4e77e6e16/port/web/halo_sdl3.py)'s documented gamepad-worker fix: SDL 3.4.16 proxies enumeration to the browser's main thread. OpenCE uses Emscripten 6.0.10 and SDL 3.4.16; this is a comparison target, not an upgrade to the retained Fuzion toolchain. Its [web entry](https://github.com/OpenCommunityEdition/OpenCE/blob/fc9deb0b10eaae1d62caedb0710968b4e77e6e16/port/web/src/web_main.c) mounts local OPFS storage and reserves a `0x80000000`–`0x88000000` memory window, requiring roughly 2.1 GiB of Wasm memory. Preserve Fuzion's existing checked memory/admission bounds rather than adopting that layout. The repository metadata declares AGPL-3.0; evaluate component licensing before copying code. Local XISO/storage patterns are later importer references; networking and map sharing remain outside M1 and do not change the local-content contract.
