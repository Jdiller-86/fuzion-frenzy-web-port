## Reproduce this bounded inventory

From the project root in PowerShell, without modifying input:

```powershell
Get-FileHash 'Fuzion Frenzy (USA)/default.xbe', 'research/reference/default.xbe' -Algorithm SHA256
Get-ChildItem 'Fuzion Frenzy (USA)' -Recurse -File | Group-Object Extension | Sort-Object Name | Select-Object Name,Count
Get-ChildItem 'Fuzion Frenzy (USA)/Packages' -Recurse -File | Select-Object FullName,Length
Get-FileHash 'Fuzion Frenzy (USA)/Packages/charactersel.xbp', 'Fuzion Frenzy (USA)/Packages/BootSeq.xbp', 'Fuzion Frenzy (USA)/Packages/MetaLevs/stadium_part_1.lnd' -Algorithm SHA256
```

For F02, read little-endian 32-bit words at `0x104` and `0x118`; subtract the former from the latter to get the certificate file offset, then inspect the fields at certificate-relative `0`, `8`, `0x0c` (80 bytes UTF-16LE), `0xa0` and `0xac` with bounds checks. This is a narrow header observation, not a validated general XBE parser. To check the earlier image match consult F03; do not repeat extraction. Check the existing project before any targeted Ghidra work.

## Follow-up: local package and browser index probe

On October 31, 2026, the published [community XBP table description](https://reshax.com/topic/18058-ripping-sounds-from-fuzion-frenzy-xbox/) supplied a hypothesis, independently checked here using the supplied build. Header fields at offsets `0x04`, `0x0c`, `0x10`, `0x28`, `0x2c` and `0x30` respectively produced a scaling factor, row count, table location, name-table location, name-table length and row-table length for this sample. The row table uses 32-byte records. All 89 package headers and ranges passed the experimental bounded index reader: 9,660 named records and 85 special rows pointing to their own name table. The four empty packages have no such row. This is range/name-table validation, not proof of payload type, complete semantic validity or compatibility with other builds. Resource names are untrusted and never used as filesystem paths.

The character-selection package's 49 rows include one special row and 48 named rows; table range is `[6160896, 6162464)` and name range is `[6160256, 6160828)`. ### Audio cue cross-check
